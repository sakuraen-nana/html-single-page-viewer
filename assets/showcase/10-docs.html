Wavelet API

一个事务型消息 API：一次调用，把短信、邮件或站内信投递到你的用户。本页覆盖认证、发送、查询与错误处理。

版本 v2.3 更新于 2026-11-18 阅读约 12 分钟 Base URL https://api.wavelet.dev

开始之前，请先在控制台创建一个项目并生成 API Key。所有接口均为 HTTPS，返回 JSON。请求体上限为 256 KB。

  • 幂等键：24 小时内重复提交同一 idempotency_key 会返回首次结果。
  • 模板变量：发送前会做变量完整性校验，缺失时返回 422。
  • 投递回调：可通过 Webhook 订阅 delivered / failed 事件。

认证

在请求头中携带 Bearer Token。生产与测试环境的 Key 前缀不同，测试 Key 不会真实发送消息。

# 所有请求都需要 Authorization 头
curl https://api.wavelet.dev/v2/channels \
  -H "Authorization: Bearer wv_live_4f9c..."
注意：不要在浏览器前端直接使用生产 Key。请通过你自己的服务端转发请求，避免 Key 泄露。

端点列表

方法路径说明
POST/v2/messages发送一条消息
GET/v2/messages/{id}查询消息投递状态
POST/v2/channels创建或更新消息通道
GET/v2/channels/{id}/stats获取最近 7 日统计
DELETE/v2/messages/{id}撤回尚未投递的消息

发送消息

请求示例

curl -X POST https://api.wavelet.dev/v2/messages \
  -H "Authorization: Bearer wv_live_4f9c..." \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+8613800000000",
    "channel": "sms",
    "template": "welcome_v3",
    "vars": { "name": "小明", "code": "839201" },
    "idempotency_key": "signup-10248"
  }'

响应 · 201 Created

{
  "id": "msg_9f2c81a7",
  "status": "queued",
  "channel": "sms",
  "to": "+86138****0000",
  "created_at": "2026-11-21T09:12:40Z",
  "estimated_cost": 0.045
}

请求参数

参数类型说明
to 必填string接收方手机号（E.164）或邮箱地址
channel 必填stringsms / email / inapp
template 必填string模板 ID，需已在控制台发布
vars 可选object模板变量；缺少必填变量时返回 422
idempotency_key 可选string幂等键，24 小时内重复请求返回同一结果
metadata 可选object自定义元数据，会原样出现在回调中

消息进入队列后状态为 queued，随后依次变为 sent、delivered 或 failed。建议通过 Webhook 监听状态变化，而不是轮询。

错误码

所有错误响应都包含 error.code 与 error.message。请根据 code 做程序判断，不要依赖 message 文案。

HTTPcode说明
400invalid_request请求体不是合法 JSON，或缺少必填参数
401invalid_tokenAuthorization 头缺失或 Key 无效
403forbidden当前 Key 无权访问该通道
404not_found消息或通道不存在
409idempotency_conflict幂等键已用于不同请求体
422template_vars_missing模板变量缺失或类型不匹配
429rate_limited超过速率限制，参考 Retry-After 头
500internal_error服务端异常，可安全重试（配合幂等键）

速率限制

默认配额为每项目 120 次请求/分钟、10,000 次/天。每个响应都会带上当前剩余额度：

X-RateLimit-Limit: 120
X-RateLimit-Remaining: 87
X-RateLimit-Reset: 1763712780
批量发送：请不要在短时间内并发打满配额。建议将发送任务排队，并使用指数退避处理 429。批量场景可申请更高的企业配额。
